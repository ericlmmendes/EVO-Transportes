# EVO Transportes - Sistema Logístico

Sistema para controle de fluxo de descarga, integração de portaria e chat em tempo real.

## Funcionalidades
- **Motoristas:** Registro de entrada com captura de foto e geolocalização.
- **Portaria:** Liberação de veículos via painel dedicado.
- **Gerenciamento:** Dashboard com estatísticas, fluxo de descarga e gestão de usuários.
- **Admin (EricLM):** Ferramentas exclusivas para limpeza de chat e banimento de usuários.
- **Chat:** Sistema global e por setor com suporte a menções (@usuário) e fotos de perfil.

## Tecnologia
- Frontend: HTML5, Tailwind CSS, FontAwesome.
- Backend: Firebase Realtime Database.
